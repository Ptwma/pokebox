3. **FPS test** σε `-game` (RTX 2060): ~5k Nanite έλατα με masked υλικό + Virtual Shadow Maps. Αν < 50 fps → μείωσε cull distance (190 m→120 m για μακρινά), ή shadows off στα πολύ μακρινά, ή λιγότερα δέντρα πέρα από 600 m.

## 6. Gotchas (ΠΑΝΤΑ)
- Commit/stage cache ανά path → πάντα νέα ονόματα (`/mnt/user-data/outputs/rNN/x_vK.py`) + έλεγχος md5 στο PC.
- Ποτέ δύο editors. Μετά από kill: μετακίνησε `Saved/Autosaves/PackageRestoreData.json` στο `Saved/Autosaves_skipped_20261022/`.
- C++ αλλαγή: save → `PBXKILL` → `PBXBUILD` → `PBXREPORT` → `PBXED` → ping.
- MCP κλήσεις < 55 s· μεγάλα jobs στην ουρά `Saved/pbx_cmd` και polling.
- `PBXRUN` στο Blender τρέχει μετά την επιστροφή της κλήσης → έλεγχος `_town.status`.
- Συντεταγμένες: Blender m, UE x=x·100, y=−y·100. Blender +y = νότος = θάλασσα. Βάρκες: πλώρη = local +X, ίσαλος z=0, τοποθέτηση στο −1.2.
- Ασφάλεια: κάρτες/Echo ΠΟΤΕ στο public repo· saves ανέγγιχτα (PBXRESTORE μετά από autotest)· όχι online· δωρεάν assets μόνο· downloads με έγκριση· ποτέ command lines του UnrealEditor (Epic token).
